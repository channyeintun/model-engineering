Reading list

This course is a path through a field that has no single textbook. These are the resources worth your time, and — more usefully — when to read each one. Opening the right thing at the wrong moment is how people give up.

How to use this page

Do not read these in parallel with the course. Finish a lesson, then open the one resource listed for it if you want more depth. Everything here is free.

read · 1For Part I — Foundations

video Karpathy — Neural Networks: Zero to Hero Lessons 01–03. Builds autograd, then a language model, from nothing. If you watch one thing on this page, watch this. Older than the rest of this list, and still the clearest. course fast.ai — Practical Deep Learning Lessons 01–02. Top-down and practical. Good if this course feels too bottom-up for you. course Dive into Deep Learning Lessons 01–03, as a reference rather than a read-through. Go here when you want a formula written out exactly, with runnable code beside it. docs PyTorch — Learn the Basics Lesson 01. Eight short pages, one sitting. The official version of this course's first lesson.

read · 2For Part II — Language models

code nanoGPT Lessons 03–04. A complete, readable GPT training repository. Read model.py line by line after Lesson 03; it will all be familiar. code nanochat Lessons 04–06, and a good model for the capstone. Tokenizer, pretraining, fine-tuning, inference and a web interface in about eight thousand lines. One --depth flag controls model size, and it runs on a single GPU or on Apple Silicon. course Hugging Face LLM Course Lessons 04–06. The library-centred view: tokenizers, datasets, Trainer. Useful once you already know what is inside the model, which is the order this course puts them in. course Hugging Face smol-course Lessons 05–06. Focused entirely on fine-tuning small models — instruction tuning, preference alignment, evaluation. The closest thing to a companion for Part II.

read · 3For Parts III and IV — Making it small, shipping it

course MIT 6.5940 — EfficientML.ai (Song Han) Lessons 06–10, and the single best academic source for this half of the course. Pruning, quantization, distillation, neural architecture search and on-device deployment, taught properly. Lecture videos and slides are public. course EfficientML — Fall 2024 course page The most recent complete run with all materials posted. Use this if the main site points at a term that has not started.

read · 4For Part V — Speech

course Hugging Face Audio Course Lessons 11–12. Unit 5 is speech recognition, Unit 6 is speech synthesis. It is the right foundation for Part V — but note that it stops before Lesson 13: it does not cover full-duplex conversation, which is still closer to research than to a standard course module.

What this list does not have

There is no single course for on-device model engineering. The material is split between deep learning courses that stop before deployment, library documentation that assumes you already know the theory, efficiency courses aimed at researchers, and runtime documentation written for people who already chose the runtime.

That gap is the reason this course exists, and it is worth knowing that the gap is real rather than assuming you have failed to find the obvious resource. You have not. It does not exist yet.

Where to go next after the course

Follow the runtime you chose in Lesson 09 and read its release notes regularly — ExecuTorch, ONNX Runtime, Core ML and llama.cpp all move quickly, and the practical limits of what fits on a phone move with them. That is the part of this field with no textbook at all, only changelogs.
